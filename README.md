# 🚀 Personal SDE Portfolio

An interactive, high-performance personal portfolio built for a **Software Development Engineer (SDE)**. Showcasing full-stack web applications, AI integration, core computer science expertise, and academic achievements.

## ✨ Features

- **⚡ Custom Splash Screen**: Smooth loading transition with custom timer and profile branding.
- **📱 Responsive Layout**: Scaled typography, dynamic layouts, and mobile-first design.
- **🎨 Dark / Modern Aesthetics**: Polished UI with smooth scrolling, grid backgrounds, and micro-interactions powered by Framer Motion.
- **💼 Project Highlights**: Direct links to live demos, repository code, and tech stack tags.
- **📩 Direct Contact Form**: Functional mail-to trigger for instant email communication.

---

## 🛠️ Tech Stack & Tools

- **Frontend**: React.js, Tailwind CSS, Framer Motion, Lucide React
- **Build Tool**: Vite / Monorepo setup
- **Languages & Core**: Java, JavaScript, Data Structures & Algorithms (DSA), REST APIs, SQL
- **Deployment**: Vercel
